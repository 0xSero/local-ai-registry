# RTX 3090 validation: Qwen3.8-27B-pi EXL3, 2026-10-05

The deployment uses one RTX 3090 with 24 GiB VRAM and the pinned SGLang EXL3 image `sha256:c8922bd7256caf1b273af7ac49221e652be9e6072c1cdec4b959f506fd415d79`. The launch profile records the validated arguments, environment and weight revision.

The [public quant](https://huggingface.co/mrq/Qwen3.8-27B-pi-exl3-3.00bpw/tree/3412e8c5a6cafdc75924fd52e339dee72de88285) was converted from [bytkim's BF16 checkpoint](https://huggingface.co/bytkim/Qwen3.8-27B-pi/tree/34d3f21045f7b41453e66c39e137cfc818a603ce), with a 3.00-bpw main-weight target, 6-bit output head, 4-bit MTP weights and 16-bit vision tower. It occupies 13.84 GB including tokenizer and supporting files. Both source and output revisions are pinned; the public model repository includes conversion provenance, checksums, license, smoke tests and coding-speed samples.

The [Pi launch](../../registry/launches/sglang-qwen3.8-27b-pi-exl3-3bpw-mtp-vision-200k.json) configures **204,800 tokens** and passed all six gates: load, chat, reasoning, tool round trip, context and speed. The context request contained **166,667 prompt tokens** and returned the planted code in **204.2 seconds**. Decode measured **132.1 tokens/s** over the canonical first 30-second window. This validates the registry's context probe, not retrieval at every position or the full maximum window. [Full run evidence](rtx-3090-24gb.qwen3.8-27b-pi.sglang-qwen3.8-27b-pi-exl3-3bpw-mtp-vision-200k.200k.20261005T080915.json).

A separate vision fixture correctly identified a red rectangle next to a blue ellipse. The [supplemental record](rtx-3090-24gb.qwen3.8-27b-pi.supplemental.20261005.json) describes the fixture and links the published conversion, Pi read/edit validation and coding-speed results. These are capability checks; no upstream accuracy or agent-benchmark score is claimed for this quantization.

## Reproduce the acceptance run

Start the frozen launch, then point the lab at that server (substitute its URL for localhost if needed):

```sh
python3 lab/lab.py try mrq/Qwen3.8-27B-pi-exl3-3.00bpw@3412e8c5a6cafdc75924fd52e339dee72de88285 --model qwen3.8-27b-pi --engine sglang-qwen3.8-27b-pi-exl3-3bpw-mtp-vision-200k --card rtx-3090-24gb --on endpoint --endpoint http://127.0.0.1:30000 --gpu 'RTX 3090'
```

The speed probe uses the lighthouse-keeper story prompt, temperature 0.8, default thinking enabled, server-tokenizer counting, and no explicit output cap. Decode timing starts at the first nonempty streamed token and covers the first 30 seconds. It includes reasoning and answer tokens. Weights and startup CUDA graphs were already loaded before measurement. This describes single-request decode, not end-to-end latency or task accuracy.
