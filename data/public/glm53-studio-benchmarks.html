Separate workloads, a 16,384-token serving limit, and three sampled repetitions each. These must not be merged with the cold vision-enabled sweep. Prefill was not cache-controlled here, so no prefill rates are inferred.

Synthetic color-order perception checks, not a general vision benchmark. Image request latency was not cache-controlled and includes processing plus output generation.

Exact greedy reference and repeatability checks

Greedy reference: synchronous plain decoding. Sampled repeat equality checks the three original MTP2 runs for each workload; it is not a claim that stochastic plain and speculative decoding produce identical token sequences.

8. Every measured run

All 22 sampled runs are listed regardless of the chart selector. CSV and JSON exports retain every recorded/derived scalar metric, including sampling parameters, memory deltas, counters and immutable receipt links.

9. Measurement method and missing coverage

  • 10 successful cold-cache requests: 512, 4,096, 8,192 and 32,768 tokens repeated twice; 65,536 and 131,072 tested once. Output length: 256 tokens.
  • Fresh nonce inside the first prefix-cache block per cold request. Prefix counter deltas confirm no cache hits. Tokenization and metric probes are outside the HTTP timing interval.
  • Temperature 1.0, top-p 0.95, top-k 20, seed 1234. Greedy correctness checks use temperature 0.
  • Streaming p50 is the median inter-event gap. p95/p99 use the empirical nearest-rank method. No first-token waiting time is included in the inter-chunk gaps.
  • Median / min / max describe observed samples only. One-point long-context results have no repetition-based uncertainty estimate.
  • The completed 131,072-token request proves capacity for that input and output length, not long-context retrieval accuracy.
  • The 261,888-input-token request was interrupted when the operator required the Mac to be released. It is not a successful 256K result.
  • No synthetic scaling curves, concurrency extrapolation, or invented peak-memory measurements.
